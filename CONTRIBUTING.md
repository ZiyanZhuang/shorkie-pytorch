# Contributing

Contributions are welcome when they preserve the evidence boundary of this
unofficial reproduction.

1. Describe the intended behavior and its relationship to the official source.
2. Add or update tests for mathematical or data-contract changes.
3. Run `pytest -q` and the privacy/path audit before proposing a change.
4. Never commit genomes, TFRecords, weights, credentials, server paths, private
   experiment logs, or requester-pays data.
5. Do not describe a pipeline smoke or synthetic task as reproduced biological
   performance.

Contributions are licensed under Apache-2.0. Official TensorFlow Shorkie
support requests belong in the official project's channels.
